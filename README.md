**LabFlow** is a web-based laboratory report management system designed to simplify the process of creating, managing, reviewing, and organizing laboratory reports. The platform provides a centralized environment to manage laboratory activities and report workflows efficiently.

## 🚀 Features

* 🔐 **Authentication & Authorization** - Secure role-based access control for Admins and Technicians.
* 📊 **Dashboard & Statistics** - Real-time overview of patients, visits, orders, and system metrics.
* 👥 **User Management** - Admin controls to provision, update, and manage staff accounts.
* 🏢 **Lab & Department Setup** - Organize medical departments, laboratories, and referring doctors.
* 🔬 **Test Catalogs** - Configurable test panels, parameters, and age/gender reference ranges.
* 👤 **Patient & Visit Intake** - Register patients, track history, and log clinical visits.
* 📦 **Order Processing** - Create and process test orders linked to patients and doctors.
* 📄 **Results & Reporting** - Record parameter results, auto-validate ranges, and issue reports.
* 📋 **Report Status Tracking** - Track the progress and current status of laboratory reports.

## 🛠️ Technologies Used

* **Frontend:** Next.js, React.js, TypeScript
* **Styling:** Tailwind CSS, shadcn/ui
* **Forms:** React Hook Form
* **Validation:** Zod
* **HTTP Client:** Axios
* **Authentication:** NextAuth
* **Backend:** REST API
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub
* **Code Editor:** Visual Studio Code

## 🔄 Workflow

1. Admins and technicians securely log into the system with role-based access.
2. Admins configure departments, laboratories, test catalogs, and parameter reference ranges.
3. Technicians register patient profiles, log clinical visits, and create test orders.
4. Technicians enter diagnostic test results and generate final laboratory reports.
5. Admins manage technician accounts, system departments, and overall activity.
6. Users track real-time report statuses and maintain complete historical patient records.

## 🎯 Objective

The objective of **LabFlow** is to digitize and simplify clinical laboratory operations by replacing manual, paper-based workflows with a centralized platform for patient intake, test catalog management, diagnostic result processing, and seamless, instant diagnostic report delivery.
